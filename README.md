# Striking acoustic signals: published code

This folder contains the code and outputs for the contribution "Striking acoustic signals: quantifying low-frequency musical drones in conspiracy documentaries", submitted to DHNB 2027.

- `./Code/` contains all the code for the analyses in the paper, including the code to generate Figure 2. To run these scripts, one would need the soundtrack data which cannot be uploaded to avoid copyright infringement. This data is available upon request, but the code can be run with any sound file, by changing the paths in the code. It also contains a `requirements.txt` file.
- `./Data/` contains the original musical drone extracted from the movie _Zeitgeist_, as well as the drone library (generated via `./Code/shift_drone_pitch.py`).
- `./Figures/` contains the two figures present in the paper. Figure 1 is extracted from [Sonic Visualiser](https://www.sonicvisualiser.org/), while Figure 2 is generated by running `./Code/drones_counts.py`.
- `./Outputs/` contains the summery of musical drone identification on the five documentaries for the two analyses present in the paper, in `.csv` and `.json` format. 

The algorithm is based on implementation of Dynamic Time Warping using different tools: [librosa](https://pypi.org/project/librosa/), [libfmp](https://pypi.org/project/libfmp/), and [soundfile](https://pypi.org/project/soundfile/).
